# ♻️ EcoRota Web

O **EcoRota** é um site que estou desenvolvendo para uma ativadade do componente curricular Introdução Ao Desenvolvimento Web, sua função é ajudar a encontrar pontos de coleta de resíduos (como medicamentos vencidos, óleo de cozinha, pilhas, baterias e lixo eletrônico). A ideia é facilitar o descarte correto no dia a dia e ajudar na sustentabilidade da cidade.

## 🎨 Paleta de Cores (Sprint 2)

Escolhi as cores do site me baseando nas cores da própria logo do projeto (que foi criado usando a IA LeonardoIA) e configurei classes usando o Tailwind.

| Uso no site | Cor | Código Hexadecimal | Nome da classe | Onde foi usada |
| :--- | :--- | :---: | :--- | :--- |
| **Cor Principal** | Verde Floresta | `#1B6B2E` | `eco-primaria` | Títulos principais, bordas dos cards e aba ativa no menu. |
| **Cor Secundária** | Azul-Petróleo | `#1C5D6B` | `eco-secundaria` | Subtítulos, botões de ação (*Buscar*, *Filtrar*, *Ver Rota*) e rodapé. |
| **Destaque** | Verde Folha | `#52A636` | `eco-destaque` | Quando passa o mouse por cima dos botões e links. |
| **Fundo da página** | Branco Gelo | `#F4F7F6` | `eco-fundo` | Fundo geral do site para não cansar a vista. |
| **Texto** | Cinza Escuro | `#1E293B` | `eco-texto` | Textos das páginas e nomes dos campos nos formulários. |
| **Fundo Suave** | Verde Bem Claro | `#E8F3EC` | `eco-suave` | Fundo do banner inicial e das etiquetas de materiais aceitos. |
| **Detalhes / Bordas** | Verde Água Claro | `#CBE3D4` | `eco-borda-suave` | Bordas leves de destaque e links no rodapé. |

### Por que escolhi essas cores?
- **Sobre o tema:** Usei os tons de verde porque lembram diretamente natureza, reciclagem e meio ambiente. O azul-petróleopor que lembra a água, já que jogar óleo e remédios no ralo contamina os rios.
- **Sobre quem vai usar:** Como muitas pessoas vão abrir o site pelo celular com pressa para achar onde descartar algo, deixei os botões e as etiquetas bem destacados para facilitar a visualização.
- **Sobre a leitura:** Coloquei letras bem escuras em fundos bem claros e letras brancas dentro dos botões escuros. Assim fica fácil de ler qualquer texto.

## 🛠️ Tecnologias Utilizadas
- **HTML:** Para montar a estrutura das páginas (`index`, `buscar`, `guia`, `indique` e `contato`).
- **Tailwind CSS:** Para fazer o visual do site e deixar funcionando bem no celular e no computador.

## 📁 Estrutura do Projeto
- `index.html` - Página inicial com a busca rápida
- `buscar.html` - Página de filtros e lista dos pontos de coleta
- `guia.html` - Guia explicando como separar e descartar cada material
- `indique.html` - Formulário para sugerir novos pontos de coleta
- `contato.html` - Informações sobre o projeto e formulário de contato
- `css/` - Pasta com os arquivos de estilo
- `js/` - Pasta reservada para a parte interativa (próxima etapa)
- `imagens/` - Logo e ícone do site
